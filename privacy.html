シンプル英単語帳

プライバシーポリシー

最終更新日: 2026年10月2日

Kohei Mikami(以下「開発者」)は、macOS / iOS アプリケーション「シンプル英単語帳」(以下「本アプリ」)における 利用者の情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。

1. 収集する情報

本アプリは、利用者を識別・特定するための個人情報(氏名・メールアドレスなど)を収集しません。 アカウント登録は不要で、開発者はサーバーを保有していません。 ただし、広告の配信・アプリ内課金の管理・利用状況の解析のために、下記 「2. 第三者が提供するサービスへの送信」に記載する情報が各事業者へ送信されます。

2. 第三者が提供するサービスへの送信

広告・課金・利用状況の解析

本アプリは、以下の外部サービスを利用しています。これらの情報は各事業者によって取り扱われ、 開発者が利用者個人を特定することはありません。

  • Google AdMob(Google LLC、広告の配信・効果測定・不正防止。iOS 版のみ): 端末の広告識別子(IDFA)、IP アドレス、端末や OS の種類、広告の表示・タップの状況などが 送信されることがあります。広告を非表示にする「Pro」を購入した場合、広告は表示されません。 Google の広告に関するポリシー / Google のプライバシーポリシー
  • Google Analytics for Firebase(Google LLC、利用状況の解析): アプリごとに割り当てられる識別子、端末や OS の種類、アプリの起動・利用時間、 IP アドレスから推定されるおおよその地域、アプリ内購入の記録などが送信されます。 登録した単語などの内容は送信されません。解析の結果は、利用者数の把握と本アプリの改善にのみ使います。 Google によるデータの使用について / Google のプライバシーポリシー
  • RevenueCat(RevenueCat, Inc.、アプリ内課金の管理。iOS 版のみ): 購入の履歴、アプリごとに割り当てられる識別子、端末や OS の種類などが送信されます。 支払いの手続きは Apple が行い、クレジットカードなどの支払い情報が開発者や RevenueCat に 渡ることはありません。 RevenueCat のプライバシーポリシー

広告識別子(IDFA)は、利用者が本アプリの表示するトラッキング許可のダイアログで 「許可」を選んだ場合にのみ利用され、利用者の興味・関心に合わせた広告の表示に使われます。 許可しなかった場合も広告は表示されますが、興味・関心に基づかない広告となります。 この設定は、端末の「設定」→「プライバシーとセキュリティ」→「トラッキング」から いつでも変更できます。「Pro」を購入した場合、このダイアログは表示されません。

辞書情報・例文の取得

単語を登録する際、辞書情報・例文を取得する目的で、入力された英単語が以下の外部サービスへ 送信されます。送信されるのは英単語・例文などの文字列のみで、利用者個人を特定する情報は含まれません。 日本語訳の多くはアプリに内蔵した辞書から取得しており、外部へは送信されません。

  • kaikki.org(発音記号・品詞・例文・訳語の取得): 入力された英単語が送信されます。 https://kaikki.org/
  • Tatoeba(例文とその日本語訳の取得): 入力された英単語が送信されます。 https://tatoeba.org/
  • DeepL API(例文の日本語訳の取得): 利用者が DeepL の API キーを登録している場合に限り、例文が送信されます。 API キーは利用者の端末内にのみ保存され、DeepL のサービスへ認証する目的以外で 外部へ送信されることはありません。 DeepL のプライバシーポリシー

3. データの保存場所

利用者が本アプリに登録した単語や設定などのデータは、利用者の端末内のローカルデータベースに 保存されます。これらのデータが開発者のサーバーへ送信・保管されることはありません。

設定で iCloud 同期を有効にした場合に限り、端末間で同期するために、登録した単語のデータが 利用者自身の iCloud(Apple が提供)に保存されます。開発者がこのデータにアクセスすることはできません。 Apple のプライバシーポリシー

4. 外部リンク

単語の発音を確認する際、Google 翻訳のページを本アプリ内または利用者の既定ブラウザで開きます。 このとき、確認する英単語が Google に送信されます。また、設定画面からレビューの投稿などを 選択した場合、App Store のページが開きます。リンク先における情報の取り扱いについては、 各サービスのプライバシーポリシー( Google / Apple )をご確認ください。

5. お子様のプライバシー

本アプリは、年齢を問わず利用者の氏名・メールアドレスなどの個人情報を収集しません。 広告・利用状況の解析のために送信される情報については、上記「2. 第三者が提供するサービスへの送信」を ご確認ください。

6. データの削除

本アプリ内のデータは、アプリ上で単語を削除する操作、または本アプリを端末から アンインストールすることで削除できます。iCloud に保存されたデータは、端末の iCloud の設定から 削除できます。開発者側に保管されるデータはないため、開発者への削除依頼は必要ありません。 各外部サービスへ送信された情報は、各事業者のプライバシーポリシーに従って取り扱われます。

7. 本ポリシーの変更

本ポリシーの内容は、法令の変更や本アプリの機能追加などに応じて改定されることがあります。 重要な変更がある場合は、本ページにて最終更新日を更新のうえ告知します。
