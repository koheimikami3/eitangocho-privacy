シンプル英単語帳

プライバシーポリシー

最終更新日: 2026年7月21日

Kohei Mikami(以下「開発者」)は、macOS アプリケーション「シンプル英単語帳」(以下「本アプリ」)における 利用者の情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。

1. 収集する情報

本アプリは、利用者を識別・特定するための個人情報を一切収集しません。 アカウント登録は不要で、利用状況の解析(アクセス解析)・行動トラッキング・広告配信のための 仕組みは一切含まれていません。

2. データの保存場所

利用者が本アプリに登録した単語や設定などのデータは、すべて利用者の端末内の ローカルデータベースにのみ保存されます。これらのデータが開発者のサーバーへ送信・保管されることは ありません(開発者はサーバーを保有していません)。

3. 第三者が提供するサービスへの送信

本アプリの「自動入力」機能を利用した場合に限り、利用者が入力した英単語や例文の文字列が、 辞書情報・翻訳を取得する目的で以下の外部サービスへ送信されます。これらに送信されるのは 入力された英単語・例文などの文字列のみで、利用者個人を特定する情報は含まれません。

  • Free Dictionary API(発音記号・品詞・例文・発音音声 URL の取得): 入力された英単語が送信されます。 https://dictionaryapi.dev/
  • DeepL API(例文の日本語訳の取得): 利用者が設定画面で DeepL の API キーを登録した場合に限り、例文が送信されます。 DeepL のプライバシーポリシー

DeepL の API キーは利用者が設定画面で入力するもので、利用者の端末内にのみ保存されます (DeepL のサービスへ認証する目的以外で外部へ送信されることはありません)。

4. 外部リンク

発音音声が取得できない単語について、発音を確認する目的で Google 翻訳のページ(URL)を 利用者の既定ブラウザで開く場合があります。リンク先の外部サービスにおける情報の取り扱いについては、 各サービスのプライバシーポリシー(例: Google のプライバシーポリシー)を ご確認ください。

5. お子様のプライバシー

本アプリは個人情報を収集しないため、年齢を問わず安心してご利用いただけます。

6. データの削除

本アプリ内のデータは、アプリ上で単語を削除する操作、または本アプリを端末から アンインストールすることで削除できます。開発者側に保管されるデータはないため、 開発者への削除依頼は必要ありません。

7. 本ポリシーの変更

本ポリシーの内容は、法令の変更や本アプリの機能追加などに応じて改定されることがあります。 重要な変更がある場合は、本ページにて最終更新日を更新のうえ告知します。
