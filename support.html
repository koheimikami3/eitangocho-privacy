シンプル英単語帳

サポート

「シンプル英単語帳」は、自分だけの英単語帳を作って学習・クイズができる macOS アプリです。 ご利用にあたってよくあるご質問をまとめました。解決しない場合は、ページ下部の窓口までお問い合わせください。

よくある質問

自動入力(辞書データの取得)ができません

自動入力はインターネット接続を利用します。ネットワーク接続をご確認ください。 また、入力した英単語が辞書に収録されていない場合は自動入力できないため、 その場合は各項目を手動で入力してください。

例文の日本語訳が自動入力されません

例文の日本語訳は DeepL の翻訳サービスを利用します。設定画面で DeepL の API キーを 登録すると、自動入力時に例文の和訳も取得されます。API キーが未設定の場合、 発音記号・品詞・例文などは取得されますが、例文の和訳は取得されません。

データのバックアップや移行はできますか

設定画面の「データ」から、登録した単語を JSON ファイルとして書き出し(エクスポート)・ 読み込み(インポート)できます。バックアップや別の端末への移行にご利用ください。

登録したデータはどこに保存されますか

すべて端末内にのみ保存されます。開発者のサーバーには送信されません。 詳しくはプライバシーポリシーをご覧ください。
